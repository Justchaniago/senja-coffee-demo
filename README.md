# Senja Coffee - Online Catalog

A modern, minimalist coffee shop catalog built with Flask. Features an elegant "Industrial Luxury" design inspired by premium coffee roasters.

## 🚀 Features

- **Multi-page Website**: Home, Shop, About, Wholesale
- **Product Catalog**: Dynamic product grid with WhatsApp integration
- **Responsive Design**: Mobile-first approach with CSS Grid
- **Hero Slideshow**: Auto-rotating background images
- **SQLite Database**: Product management system
- **Dark Theme**: Deep charcoal (#1C1C1C) with sage green accents

## 🛠️ Tech Stack

- **Backend**: Flask 3.0.0, SQLAlchemy
- **Frontend**: HTML5, CSS3, Vanilla JavaScript
- **Database**: SQLite
- **Deployment**: Vercel

## 📦 Installation

1. Clone the repository:
```bash
git clone https://github.com/YOUR_USERNAME/senja-coffee-demo.git
cd senja-coffee-demo
```

2. Create virtual environment:
```bash
python3 -m venv venv
source venv/bin/activate  # On Windows: venv\Scripts\activate
```

3. Install dependencies:
```bash
pip install -r requirements.txt
```

4. Run the application:
```bash
python3 app.py
```

5. Open browser at `http://127.0.0.1:5000`

## 🌐 Deployment

This project is configured for Vercel deployment:

1. Push to GitHub
2. Import project in Vercel
3. Deploy automatically
